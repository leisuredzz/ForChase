## 换成真实数据要改什么

只要保证**结构一致**，把文件替换成你自己的数据即可，notebook 里的解析代码一行都不用改。

如果你想用真实的历史疫情数据，可以：
1. 从公开数据源下载（例如各国卫生部开放数据、Our World in Data 等）
2. 转成上面的 JSON 结构
3. 覆盖对应文件

## 想验证 jsonp 结构长什么样

打开 `折线图数据/美国.txt`，你会看到它开头是 `jsonp_1629344292311_69436(`，结尾是 `)`。
这就是"JSONP"格式 —— 它是为了让网页能跨域取数据而发明的包装方式，
解析前必须先把这层壳剥掉，`折线图.ipynb` 里有详细说明。
