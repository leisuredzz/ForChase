# PythonLearnProject

一个从零开始的 Python 学习项目：**基础语法 → 数据结构 → 面向对象 → 模块与包 → 数据分析三件套 → 可视化 → 数据库**。

代码全部是 **Jupyter Notebook**，可以**逐格运行**；每个知识点都配了「常见坑清单」和「动手练习」。

目录按 **`01` ~ `10` 编号**排好，**编号就是学习顺序**，照着数字一路往下走即可。

---

## 一、快速开始

本项目用 **uv** 管理 Python 环境和依赖（不再使用 Conda）。

```bash
# 1) 安装依赖（会自动创建 .venv 虚拟环境）
uv sync

# 2) 启动 Jupyter，在浏览器里打开笔记本
uv run jupyter lab
```

如果你习惯用 VS Code：用 `Ctrl+Shift+P` → `Python: Select Interpreter` →
选择项目里的 `.venv`，然后直接打开 `.ipynb` 运行即可。

> 项目里已经放好了 `.vscode/settings.json`，把默认解释器指向
> `${workspaceFolder}/.venv/Scripts/python.exe`，正常打开就会自动用对，
> **不需要每次手动选**。

> **如果 VS Code 报「无法解析解释器路径 …anaconda3…」**
> 那是因为以前用 Conda 时手动选过 anaconda 的解释器，卸载 Conda 后就失效了。
> 解决：`Ctrl+Shift+P` → `Python: Select Interpreter` → 选 `.venv` 那个
> （显示为 `Python 3.12.14 ('.venv')` 或 `PythonLearnProject (3.12.14)`），
> 然后 `Ctrl+Shift+P` → `Developer: Reload Window` 重载窗口即可。

> **本项目的 Python 版本是 3.12**（见 `.python-version`）。
> `uv` 会自动下载和管理对应版本，不需要你手工装 Python。

**入口笔记：[`src/pythonlearnproject/00.学习路线.ipynb`](src/pythonlearnproject/00.学习路线.ipynb)**
（里面有完整目录树，还会自动扫描列出所有篇目，永不过期。）

### 命名规则（一眼看懂顺序）

| 形式 | 含义 | 例子 |
|---|---|---|
| `NN.名称/` | **模块**（第 NN 个学习阶段） | `07.pandas/` |
| `NN.MM-名称.ipynb` | 模块内**第 MM 篇**笔记 | `07.05-DataFrame.ipynb` |
| 不带编号的文件/目录 | **数据或产物**，不是学习内容 | `data.txt`、`生成文件/` |

> **为什么编号要补零（`01` 而不是 `1`）？**
> 因为不补零时字符串排序会把 `10` 排到 `2` 前面，文件夹顺序就乱了。

### ⚠️ 一个必须知道的技术约束

**以数字开头、且含点号的目录，不能作为 Python 包的导入路径。**
（`import 05.模块与包` 是语法错误 —— Python 要求路径每段都是合法标识符。）

所以：

| 目录 | 能不能 `import` |
|---|---|
| `01.基础概念/` ~ `10.MySQL/` | ❌ 只能当文件夹 |
| `05.模块与包/my_uyils/`（里面那层） | ✅ 可以 import |

处理方式是把它所在的**上一层目录**加进 `sys.path`，再 import 里面那一层。
完整讲解见 [`05.01-模块与包.ipynb`](src/pythonlearnproject/05.模块与包/05.01-模块与包.ipynb)。

## 六、⚠️ 版本差异提醒（很重要）

本项目用的依赖版本较新，从网上或旧教程抄代码时注意这几处：

| 依赖 | 版本 | 变化 |
|---|---|---|
| **pandas** | 3.x | 字符串列的 dtype 是 `str` 而**不是** `object`（旧版是 `object`） |
| | | `resample()` 的 `'M'`/`'Q'`/`'Y'` **已直接报错**，必须写 `'ME'`/`'QE'`/`'YE'` |
| | | `Series.fillna(method='ffill')` **已移除**，改用 `.ffill()` / `.bfill()` |
| | | `to_json()` 的日期默认写成毫秒时间戳（已废弃），建议显式 `date_format='iso'` |
| | | `read_json()` 收到 JSON **字符串**时会当成文件路径，需要 `io.StringIO(...)` 包一下 |
| **pygame** | 2.6+ | 对**零向量**调用 `Vector2.normalize()` 会**直接抛 ValueError**（老版本是静默返回零向量） |
| **matplotlib** | 3.x | 在 Jupyter 里 `plt.show()` 图直接显示在单元格下方；但**用 `.py` 脚本跑时会弹出一个窗口并卡住**，等你去关它。脚本里跑要设 `MPLBACKEND=Agg` |

> 另外 `resample('ME')` 和 `to_period('M')` 在同一个版本里用的是**两套别名**，
> 这一点在 `07.07-时间序列处理.ipynb` 里有专门说明。

## 八、学习建议

1. **每篇都自己跑一遍**，然后**改参数看结果怎么变** —— 光看是不会的
2. 遇到报错别慌，**认真读报错信息**：Python 会明确告诉你是哪一行、什么类型的错
3. 把「动手练习」真的做一遍再看答案，效果比读十遍讲解都好
4. **复习时优先看每篇结尾的「常见坑清单」**，那是精华浓缩
5. 学到后面**回头看前面**，很多当时不懂的点会突然通

## 九、关于重新编译（给维护者）

`src/` 下的 `.ipynb` 是**从 `.workbuddy/build/` 下的 `*.src.py`（py:percent 格式）编译生成的**。
手改 `.ipynb` 的 JSON 很容易出错，推荐改源文件后重新编译：

```bash
python .workbuddy/nb_build.py        # 编译全部
python .workbuddy/nb_test.py 某个.ipynb   # 单独跑一个笔记本验证
```

源文件第一行的 `# @target: 相对路径.ipynb` 决定它编译到哪。
