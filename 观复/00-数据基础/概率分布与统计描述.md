# 概率分布与统计描述

> **建议先读**：[[数据认知框架]]，先区分数值类型、单位和观察对象。
> **核验状态**：部分实测——偏度反例、峰度下界与常见分布的矩公式曾在 Python 3.13 上核算；第 1～7 节的视频观点未与原始视频逐句比对。详见 [[知识库质量审计]]。

这篇笔记回答一个问题：面对一批数值，或者一个结果事先不确定的现象，怎样用**少数几个数字**把它的"样子"描述清楚。

理解路径是：先弄清"分布"是什么，再用**矩**这一条主线，把描述分布的三类指标——中心位置、离散程度、尾部特征——串成一个整体；最后补充常见分布和实际用法，以及最容易搞错的几个地方。

> **来源说明**：第 1～7 节整理自 B站视频《概率分布的 12 个核心概念》（黑纹白斑马译制，原作为 RiskByNumbers《12 Concepts That Change How You See Probability Distributions》，2025-05-03），并做了结构化与术语校正。标注为**补充**的章节（随机变量的形式化定义、常见分布速览、实际应用、代码、误区扩展）不属于原视频内容，是整理时补入的基础知识。视频只讨论**离散型**随机变量。

## 背景：为什么需要"分布"这个概念

生活里大量数值是事先不确定的：

- 明天下多少毫米雨；
- 下一笔订单的金额是多少；
- 某只股票明天的收益率；
- 一批 1000 件产品里有多少件次品。

这些量的共同点是：**单次结果无法预知，但长期重复会呈现规律**。

把两样东西放在一起，就构成了这个随机现象的**分布**：

1. 它**可能取哪些值**；
2. 每个值出现的**可能性有多大**。

> **类比**：分布像一张人口普查表。它不是只告诉你"平均身高 170cm"，而是告诉你每个身高段各有多少人。有了这张表，你才能回答"有多少人超过 190cm"这类问题。

这直接引出一个结论：

> **只用一个平均值来描述数据，一定会丢信息。** 丢了"有多散"，也丢了"极端值有多容易出现"。

## 问题：平均分相同，两个班一样吗

A 班 50 人，考试成绩全是 70 分。
B 班 50 人，25 人 30 分，25 人 110 分。

两个班平均分都是 70。但显然不能认为"这两个班情况一样"。

要把它说清楚，至少得回答三个问题：

| 问题 | 回答它的指标 |
| --- | --- |
| 中心在哪里？ | 众数、中位数、均值 |
| 有多散？ | 方差、标准差、变异系数 |
| 尾巴什么样？ | 偏度、峰度 |

而这三类指标背后，站着同一个数学概念：**矩（moment）**。这就是本笔记的主线。

## 一、随机变量与分布（补充）

### 随机变量

**随机变量（random variable）**就是"把随机的结果映射成一个数字"的规则。

- 抛一枚硬币，记正面为 1、反面为 0 → 随机变量 `X ∈ {0, 1}`；
- 记录一小时内的来电次数 → `X ∈ {0, 1, 2, ...}`。

### 离散型与连续型

| 类型 | 取值特点 | 例子 |
| --- | --- | --- |
| 离散型 | 取值可一个一个列出来 | 次品件数、来电次数、骰子点数 |
| 连续型 | 取值填满一个区间，可无限细分 | 身高、温度、等待时间 |

这个区分很重要：它决定了"概率怎么表达"。**视频只研究离散型**，因为列举取值更直观；但三类描述指标和矩的结论对连续型同样成立。

### 三种表达方式

| 名称 | 适用 | 回答什么 | 记号 |
| --- | --- | --- | --- |
| 概率质量函数 PMF | 离散 | `P(X = 某个具体值)` 是多少 | `p(x)` |
| 概率密度函数 PDF | 连续 | 一个区间内的概率 = 曲线下的**面积** | `f(x)` |
| 累积分布函数 CDF | 两者皆可 | `P(X ≤ x)` 是多少 | `F(x)` |

> **容易踩的坑**：连续型随机变量取**某一个精确值**的概率是 0。例如"身高恰好等于 170.0000…cm"的概率为 0，只有"身高在 169.5 到 170.5 之间"才有非零概率。所以连续型不能用 PMF，只能用 PDF 的**区间面积**。这也是为什么下面所有例子都优先用离散分布——它们能逐个点算概率。

## 二、矩：串起所有指标的一条主线

### 物理来源

**矩**来自物理学。用扳手拧螺母时：

> **力矩 = 力 × 力臂**

拧紧它，不光靠力气大，还靠**手离螺母足够远**。所以衡量"效果"时，**距离和大小同样重要**。

统计学把同样的思路用在数据上：每一个取值离参考点有多远（力臂）、它出现的概率有多大（权重），两者乘起来加权，就得到矩。

### 三种矩

| 名称 | 定义 | 参考轴 |
| --- | --- | --- |
| **原点矩** | `E(X^k)` | 相对**零点** |
| **中心矩** | `E[(X − μ)^k]` | 相对**均值 μ** |
| **标准化矩** | 中心矩 ÷ `σ^k` | 相对均值，且消除尺度 |

其中 `E(·)` 表示"按概率加权求平均"，`μ` 是均值，`σ` 是标准差。

### 每一阶矩对应一个指标

~~~mermaid
flowchart TD
    A[矩 moment] --> B[原点矩 E X 的 k 次方]
    A --> C[中心矩 E X 减 mu 的 k 次方]
    B --> D[一阶原点矩 = 均值]
    C --> E[二阶中心矩 = 方差]
    C --> F[三阶 标准化 = 偏度]
    C --> G[四阶 标准化 = 峰度]
    E --> H[方差再开根号 = 标准差]
    H --> I[标准差除以均值 = 变异系数]
~~~

| k | 中心矩 | 得到什么 |
| --- | --- | --- |
| 1 | `E(X − μ)` | 恒等于 0，没有信息 |
| 2 | `E[(X − μ)²]` | **方差** |
| 3 | `E[(X − μ)³]` | 除以 `σ³` 后得到**偏度** |
| 4 | `E[(X − μ)⁴]` | 除以 `σ⁴` 后得到**峰度** |

> **理解方式的选择**：视频作者更倾向"相对某个参考轴的总矩"这个物理视角，而不是纯代数上的"加权平均"。前者更好懂，后者更好算——两种说法描述的是同一件事。

## 三、中心趋势：三个"中心"未必重合

| 指标 | 定义 | 类比 | 什么时候最有用 |
| --- | --- | --- | --- |
| **众数**（mode） | 概率最大的那个取值 | 人群里出现次数最多的那个身高 | 类别数据、最典型情况 |
| **中位数**（median） | 上下各 50% 概率的分界点 | 排队时站在正中间的人 | 存在极端值时 |
| **均值**（mean／期望） | 按概率加权的平均，即一阶原点矩 | 把分布"重心"撑起来的那一点 | 需要参与后续计算时 |

三个概念的差别，用一个例子就能看清：

> 5 个人的月收入分别是 5000、5000、6000、7000、50000 元。
> - 众数 = 5000（出现次数最多）
> - 中位数 = 6000（正中间）
> - 均值 = 14600（被那个 50000 拉高了）

**均值是"重心"**：把分布画在一条横杆上，均值就是那个能用一根手指顶住、两边平衡的点。这也解释了均值为什么怕极端值——离重心很远的那个点，力臂很长，会明显把支点拽过去。

**中位数抗极端值**：把收入改成 500 万，中位数几乎不动，均值会飞起来。所以在**收入、房价**这类右偏数据中，报道常用中位数而不是均值。

> **关系**：在**非对称**分布中三者通常不相等。以右偏（右尾长）为例，常见顺序是
> `众数 < 中位数 < 均值`。
> 在**对称**分布中三者可能重合。

**众数信息量最少**——它只盯着一个点，不关心其他取值如何分布，所以还需要中位数和均值来补充。

## 四、离散程度：从方差到变异系数

只知道中心在哪里还不够。A 班和 B 班平均分都是 70，差别在"散不散"。

| 指标 | 定义 | 为什么需要它 |
| --- | --- | --- |
| **方差** `σ²` | 二阶中心矩；各取值偏离均值**平方**的加权平均 | 平方让正负偏离不再抵消，且恒为非负 |
| **标准差** `σ` | 方差的平方根 | 方差被平方过，单位与 X 不一致；开根号后单位对齐 |
| **变异系数** `CV` | `σ / μ` | 用一个数同时表达"散"和"中心在哪"，且没有量纲 |

### 方差为什么要平方

如果把偏离量 `(X − μ)` 直接相加，正偏离和负偏离会互相抵消，结果永远是 0，没有意义。取平方解决了三件事：

1. **消除符号**，负偏离不再抵消正偏离；
2. **放大远离中心的点**，符合"越离群越该被注意"的直觉；
3. 数学上性质良好（可导、可分解）。

### 标准差为什么还要开根号

方差的单位是"原单位的平方"。用身高的平方厘米去描述"身高波动多少"很难解释。开根号后，标准差和原始数据**单位一致**：

> 平均身高 170cm，标准差 6cm —— 这句话立刻能读懂。

### 变异系数的价值

`CV = σ / μ` 把"离散程度"和"中心位置"压成一个**无量纲**的比值。

它解决的是**跨尺度比较**问题：

> 身高（均值 170cm，标准差 6cm，CV ≈ 3.5%）比体重（均值 65kg，标准差 10kg，CV ≈ 15.4%）相对更稳定。
> 直接用标准差比较 6cm 和 10kg 是没有意义的，单位都不同。

> **注意它的失效场景**：当均值接近 0 时，`CV` 会变得极大甚至无意义。例如某指标均值为 0.01、标准差为 0.5，CV = 50，这个数字代表不了"不稳定"。**只有当数据是比率尺度、且均值显著大于 0 时，CV 才有解释力。**

## 五、标准化：让不同分布可比

对每个取值做两步操作，得到 **Z 值**：

~~~text
Z = (X − μ) / σ

第一步  减均值  → 把分布中心平移到 0，消除"位置"差异
第二步  除标准差 → 把分布整体缩放到同一尺度，消除"宽窄"差异
~~~

**效果**：标准化后的变量**均值恒为 0、标准差恒为 1**，而**形状完全不变**（偏度、峰度都不变）。

**为什么要这么做**：

> 一个分布在 0 附近，一个在 1000 附近；一个很窄，一个很宽。
> 直接把它们画在一起，除了"一个在左一个在右"什么都看不出来。
> 标准化之后，位置和尺度被抹掉，**剩下的差异只能是形状差异**。

这是比较尾部特征的前提。视频特别强调：**不先标准化，就会对"谁的尾巴更重"得出完全相反的结论**（见第 7 节的例子）。

> **类比**：把不同货币的金额都换算成同一种货币，才谈得上比较购买力。标准化就是"把不同分布换算成同一种刻度"。

## 六、偏度：两个尾部相对大小的差异

**偏度（skewness）= 三阶标准化矩**，即把标准化后的值取**三次方**再加权求和。

### 为什么能反映左右

指数是**奇数**（3）：负值的立方仍是负的，正值的立方仍是正的。所以

- 均值**左侧**的偏离贡献**负**值；
- 均值**右侧**的偏离贡献**正**值。

两者相减，剩下的量就代表"哪一侧的尾巴更重"。

| 偏度符号 | 含义 |
| --- | --- |
| 正值 | **右尾重**（右侧有更长／更多的极端值），数据向右偏 |
| 负值 | **左尾重**，数据向左偏 |
| 接近 0 | 两侧尾部贡献大致抵消 |

**大小**反映两个尾部**相对大小**的差异程度，而不是"离对称差多远"。

### 最容易被搞错的一点

> ⚠️ **偏度 = 0 不代表分布对称。**

**对称 ⇒ 偏度 = 0** 是对的；但**偏度 = 0 ⇏ 对称**。视频给出了反例：右尾更长但更细、左尾更短但更粗，两边的贡献恰好抵消，偏度仍然为 0。

一个可以手算验证的最小反例（补充，取值与概率已用精确有理数核验）：

> **取值 `{0, 1, 2}`，概率分别为 `1/16`、`5/8`、`5/16`。**
> - 均值 `μ = 1.25`
> - 三阶中心矩为 0 → **偏度 = 0**
> - 但左端概率 `1/16`、右端概率 `5/16`，**明显不对称**

验算：`(1/16)(0−1.25)³ + (5/8)(1−0.25)³ + (5/16)(2−1.25)³ ≈ −0.1221 − 0.0098 + 0.1318 = 0`。

**正确理解**：偏度是**尾部相对大小**的度量，不是对称性的度量。判断对称性，要直接看分布本身，而不是只看偏度这一个数字。

> 补充一个严谨性提醒：对称分布只有在三阶矩存在时偏度才为 0。像柯西分布这类"尾巴太重"的分布，均值都不存在，偏度自然无从谈起。

## 七、峰度：尾部总大小，不是"尖不尖"

**峰度（kurtosis）= 四阶标准化矩**，把标准化后的值取**四次方**再加权求和。

### 为什么它衡量尾部

指数是**偶数**（4），所以结果**恒为非负**，不会出现正负抵消。而四次方对**远离 0 的值增长极快**：

> 标准化值 Z 为 4 时，`Z⁴ = 256`；Z 为 1 时只有 1。
> 也就是说，**远处的尾巴对峰度的贡献，远远盖过中心附近的点**。

所以峰度本质上是**尾部（离群值）总重量**的度量。

| 基准 | 数值 |
| --- | --- |
| 正态分布峰度 | **3** |
| **超额峰度**（excess kurtosis） | 峰度 − 3，即"比正态的尾巴重多少" |
| 峰度下界 | 1（由"两点等概率分布"达到） |

- 超额峰度 **> 0**：比正态尾重（厚尾、尖峰）；
- 超额峰度 **< 0**：比正态尾轻；
- 均匀分布：峰度 **1.8**，超额 **−1.2**，是"轻尾"的典型。

> ⚠️ **峰度不是"尖不尖"**。一个分布可以在中心很尖同时尾巴很薄，也可以在中心很平同时尾巴很厚。真正被峰度捕捉的是**尾部**，不是顶部的形状。这一点常被"尖峰厚尾"这个说法混淆。

### 均匀分布的反直觉案例

视频后半段用了一个很有说服力的例子（数值已核验）：

> 把随机变量"展平"成一个区间上的均匀分布，直觉上尾巴好像更重了——原来集中在中间，现在连区间两端的值都有了非零概率。
>
> 但事实相反：
> - 均匀分布**标准差同时大幅增大**；
> - 标准化之后，所有取值都落在 `[−√3, +√3] ≈ [−1.73, +1.73]` 之内；
> - 也就是说，**超出 `[−2, +2]` 的概率恰好为 0**，尾巴其实**更轻**；
> - 峰度只有 1.8（超额 −1.2），远低于正态的 3。

**结论**：不先做标准化，单凭"看起来两端有值"就判断尾巴更重，会得出完全错误的结论。

## 八、常见概率分布速览（补充）

上面讲的是"怎么描述一个分布"。实际工作中更常见的是反过来：**先认出这是哪一类分布，再套用现成的性质**。以下是基础清单（均值、方差、偏度、超额峰度均为解析公式，整理时已逐项数值核验）。

| 分布 | 类型 | 描述什么 | 参数 | 均值 | 方差 | 偏度 | 超额峰度 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 均匀 U(a, b) | 连续 | 区间内完全无偏好 | 端点 a、b | (a+b)/2 | (b−a)²/12 | 0 | −1.2 |
| 正态 N(μ, σ²) | 连续 | 大量独立因素叠加 | μ、σ² | μ | σ² | 0 | 0 |
| 伯努利 Ber(p) | 离散 | 一次"成功／失败" | p | p | p(1−p) | (1−2p)/√(p(1−p)) | (1−6p(1−p))/(p(1−p)) |
| 二项 B(n, p) | 离散 | n 次独立试验的成功次数 | n、p | np | np(1−p) | (1−2p)/√(np(1−p)) | (1−6p(1−p))/(np(1−p)) |
| 泊松 Poi(λ) | 离散 | 单位时间／空间内事件发生次数 | λ | λ | λ | 1/√λ | 1/λ |
| 几何 Geom(p) | 离散 | 首次成功所需的试验次数 | p | 1/p | (1−p)/p² | (2−p)/√(1−p) | — |
| 指数 Exp(λ) | 连续 | 泊松过程中两次事件的间隔时间 | λ | 1/λ | 1/λ² | 2 | 6 |

### 怎么选

| 你要描述的现象 | 用哪个 |
| --- | --- |
| 一次试验只有成功／失败两种结果 | 伯努利 |
| 固定次数试验里成功了几次 | 二项 |
| 一段时间里"稀有事"发生了多少次 | 泊松 |
| 等多少次才第一次成功 | 几何 |
| 两次事件间隔多久 | 指数 |
| 大量独立小因素叠加的总体效果 | 正态 |
| 完全没有任何信息可用 | 均匀 |

### 几个联系（便于记忆）

- **泊松是二项的极限**：当试验次数 n 很大、单次成功概率 p 很小时，二项分布近似泊松分布（`λ = np`）。
- **指数和泊松是一对**：泊松描述"次数"，指数描述同一种过程里"间隔时间"。
- **指数分布无记忆性**：已经等了 10 分钟，对"还要再等多久"的概率判断没有任何影响。
- 二项／泊松的偏度与超额峰度都是**正的**，且随着 n 或 λ 增大而趋近 0——样本量越大，分布越接近正态，这也正是中心极限定理的直观体现。

## 九、怎么用：从描述到判断（补充）

### 1. 先画图，再算数

四个数字（均值、标准差、偏度、峰度）是摘要，不是全部。**两个分布可以有完全相同的四个统计量，形状却不同**。

> 有已知的反例族（Anscombe 四组数据、Datasaurus 十二组数据）专门说明这件事：统计量相同，散点图形态可以天差地别。

所以标准流程是：**先看直方图／箱线图，再用指标补充细节**，而不是只算不画。

### 2. 识别异常值

| 方法 | 判据 | 适用与风险 |
| --- | --- | --- |
| Z 值法 | `\|Z\| > 3` | 假设近似正态；**厚尾分布下会误伤大量正常值** |
| 3σ 法则 | 超出 `μ ± 3σ` | 同上，仅对正态类数据有效 |
| IQR 法则 | 超出 `[Q1 − 1.5·IQR, Q3 + 1.5·IQR]` | 用中位数和四分位数，**不依赖正态假设**，更稳健 |

> 这正是本笔记前面结论的直接应用：**先判断尾部轻重，再选异常值规则**。对收益率、点击量这类厚尾数据，直接用 3σ 会大面积误报。

### 3. 判断"能不能用正态假设"

很多统计方法（t 检验、线性回归的误差假设、控制图）都要求近似正态。检查方式：

- 看直方图是否对称、单峰；
- 看偏度是否接近 0、超额峰度是否接近 0；
- 用 Q-Q 图对照正态分位数。

**不要**只看均值就假设正态——偏度和峰度就是为此准备的。

### 4. A／B 测试与中心极限定理

单次观测的分布可能很偏，但**大量独立观测的均值**会趋近正态分布，这就是中心极限定理。它解释了：

- 为什么可以用均值和标准误给"两组差异"做显著性判断；
- 为什么样本量越大，均值越稳定（标准误 `= σ / √n`）；
- 为什么极端偏态的指标（如收入、订单金额）需要更大样本量才能得到可靠结论。

### 5. 金融场景：尖峰厚尾（回链）

股票、汇率的**日收益率分布**通常不是正态：中心比正态更尖、尾部比正态更厚（超额峰度明显大于 0），且常有偏度。

这直接影响风险度量：

- 用正态假设估算"极端下跌概率"会**系统性低估**；
- 波动率只能描述变化的剧烈程度，不等于全部风险。

详见 [[金融市场与交易基础]] 中"收益、风险与不确定性"一节。

### 6. 用代码算这些指标

下面这段只用标准库，可直接运行（整理时已在本机 Python 3.13 上运行核验）：

~~~python
from math import sqrt

def describe(xs, ps):
    """xs: 取值列表；ps: 对应概率，需满足 sum(ps) == 1"""
    mu = sum(x * p for x, p in zip(xs, ps))
    m2 = sum(p * (x - mu) ** 2 for x, p in zip(xs, ps))   # 二阶中心矩 = 方差
    m3 = sum(p * (x - mu) ** 3 for x, p in zip(xs, ps))   # 三阶中心矩
    m4 = sum(p * (x - mu) ** 4 for x, p in zip(xs, ps))   # 四阶中心矩
    sd = sqrt(m2)
    return {
        "均值": mu,
        "标准差": sd,
        "偏度": m3 / sd ** 3,
        "峰度": m4 / m2 ** 2,
        "超额峰度": m4 / m2 ** 2 - 3,
    }

# 第 6 节的反例：偏度 = 0，但分布并不对称
print(describe([0, 1, 2], [1/16, 5/8, 5/16]))
# {'均值': 1.25, '标准差': 0.559..., '偏度': 0.0, '峰度': 2.6, '超额峰度': -0.4}

# 离散均匀分布：峰度应接近 1.8
n = 20000
print(describe([i / n for i in range(n + 1)], [1 / (n + 1)] * (n + 1))["峰度"])
# 1.79999...
~~~

> **实用提醒**：对**样本数据**（不是理论分布）计算时，`pandas.Series.skew()` 和 `.kurt()` 默认会做**无偏修正**，其中 `.kurt()` 返回的是**超额峰度**（正态为 0）；`scipy.stats.skew` 和 `scipy.stats.kurtosis` 的默认参数与 pandas 不同。**同一批数据换一个库，数值会有差异**，跨库比较前先确认参数（以所用版本文档为准）。

## 常见误区

- **偏度 = 0 就认为分布对称**——错。偏度只衡量两侧尾部的相对大小，不对称但偏度恰为 0 的分布是存在的。
- **把峰度理解成"尖不尖"**——错。峰度反映的是**尾部**的重量，中心顶部再尖也影响有限。
- **只用平均值描述数据**——丢掉了离散程度和尾部信息。
- **直接拿标准差比较不同量纲的数据**——应先转成变异系数。
- **不标准化就判断"谁的尾巴更重"**——会被位置和尺度干扰，结论可能完全相反。
- **看到连续变量的 PDF 就当成"某一点的概率"**——单点概率为 0，只有区间有概率。
- **对任何数据都用 3σ 找异常值**——只在近似正态时成立，厚尾数据请改用 IQR 法则。
- **样本量很小时过分相信偏度／峰度数值**——高阶矩对个别极端值极其敏感，稳定性远低于均值。
- **认为两个分布的四个统计量相同就意味着两个分布相同**——统计量是摘要，不是分布本身。

## 现阶段认知

概率分布是"用少数几个数字概括不确定性"的语言，而**矩**是这门语言的语法：

1. **一阶矩**（均值）说中心在哪里——但要小心它怕极端值；
2. **二阶矩**（方差／标准差）说有多散——记得用变异系数处理量纲问题；
3. **三阶矩**（偏度）说两侧尾部谁更重——它不等于对称性；
4. **四阶矩**（峰度）说尾部整体有多重——它不等于"尖"。

而这四件事能被比较的前提，是**先做标准化**：只有抹掉位置和尺度，剩下的差异才是形状差异。

真正理解一个分布，需要依次回答：

1. 它是离散型还是连续型？
2. 中心在哪里，用什么指标表示最合适？
3. 离散程度多大，能否跨数据集比较？
4. 两侧尾部是否对称？
5. 尾部比正态重还是轻？
6. 是否近似于某个已知分布（正态／泊松／二项）？
7. 在这个分布上，哪些统计方法的前提假设成立？
8. 极端值用哪条规则识别？

这套问题是从描述性统计走向推断统计、风险度量和异常检测的共同地基，也是 [[数据认知框架]] 里"一行数据的粒度与业务含义"之后，理解**数值本身如何分布**的下一步。
