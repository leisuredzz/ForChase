### M 语言语义的一处修正

来源材料把下面这种嵌套 `each` 的写法判为“错误”，理由是“两个 `each` 都试图使用 `_`，Power Query 无法区分”：

~~~text
Table.AddColumn(源, "高金额订单", each Table.SelectRows(源, each [金额] > 100))
~~~

对照微软 M 语言规范，这一判断**不成立**：`each` 是“声明一个只接受参数 `_` 的函数的语法简写”（规范原文：*a syntactic shorthand for declaring untyped functions taking a single parameter named `_`*），每层 `each` 各自引入自己的 `_`，**内层遮蔽外层**，不存在歧义。真正需要 `(x) =>` 的场合是**内层要引用外层的值**。结论已写入 [[Power Query 数据处理]]，并标明未在本机求值验证、依据为官方规范的作用域规则。
