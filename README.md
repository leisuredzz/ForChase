# ForChase

个人学习笔记与练习代码，集中存放并做云端备份。

## 目录结构

- **`观复/`** — Obsidian 知识库。按「数据基础 / 编程与开发 / 数据工程 / 数据分析与报表 / 智能系统 / 业务领域」六大分类整理的 Markdown 笔记，入口见 `观复/首页.md`。
- **`PythonLearnProject/`** — Python 学习项目。以 Jupyter Notebook 为主，覆盖基础语法、NumPy、pandas、Matplotlib、MySQL、数据可视化等，配套源码在 `src/`。

本地虚拟环境（`.venv`）、工具缓存（`.workbuddy`）与个人文件不纳入版本管理，详见 `.gitignore`。
